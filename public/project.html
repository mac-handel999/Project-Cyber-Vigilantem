Module 01

Safe Browse URL Checker

Submit a URL or domain to be checked against Google's live Safe Browsing database for phishing, malware and other malicious behaviour.

Protocol is optional — example.com works as well as a full https:// address.

Controlled test target

Google's research test URL always returns a malicious verdict, which makes it a safe way to confirm the checker is wired up correctly:

http://malware.testing.google.test/testing/malware/

A clean verdict is not a guarantee of safety. Verify the sender before entering credentials anywhere.

Safe Browse URL Checker

Available as an installable PWA in Chrome and as a browser extension. For a clean result, verify the sender's identity before interacting with the link.
