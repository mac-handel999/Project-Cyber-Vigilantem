Module 02

Threat Research Engine

The engine assembles live search intelligence into a structured briefing. Queries work best when they name a specific technical identifier or a clear security goal, rather than a broad topic.

Vulnerability & CVE analysis

Use these when you see a security alert and need an immediate breakdown.

  • CVE-2026-12345 — a specific CVE ID gives the most accurate results.
  • Apache Struts remote code execution vulnerability
  • Is there a PoC for the recent Windows print spooler bug?
  • Critical vulnerabilities in OpenSSL, 2026

Threat actor & TTP profiling

Use these to understand the behaviour of known groups.

  • APT29 TTPs — TTP stands for tactics, techniques and procedures.
  • Lazarus Group campaigns in 2026
  • Latest IOCs for Emotet malware
  • How does the DarkVault ransomware-as-a-service model operate?

Defensive configuration & hardening

Use these for actionable advice on securing your own infrastructure.

  • How to harden Nginx against DDoS
  • Best practice configuration for IPFire firewall
  • Secure coding practices for Node.js authentication
  • How to detect lateral movement in a Linux network

Trending alerts

  • CISA KEV catalog update — KEV is the Known Exploited Vulnerabilities list.
  • Top cybersecurity threats this week
  • New zero-day exploit browser security

Getting better results

Combine a technology + threat + goal structure. For example: WordPress SQL injection mitigation.

You can also set the depth of the answer directly in the query:

  • Summarise the threat for a C-suite executive: [CVE-2026-9999]
  • List all technical indicators of compromise for: [malware name]
  • Explain how to patch: [vulnerability name] in simple steps
Module 01

Safe Browse URL Checker

The checker gives immediate security feedback on any web address by cross-referencing it against Google's global Safe Browsing database. It helps identify phishing attempts, malware distribution sites and other malicious infrastructure.

Running a check

  • Input the URL. The protocol is optional — example.com works as well as https://example.com.
  • Submit the form. Press the search button or Enter.
  • Review the verdict. A result returns as either clean or suspicious.

Reading the results

Clean

No threats were identified. This is not a guarantee that the site is safe, so continue to exercise normal caution.

Malicious / phishing

The URL is flagged for hosting dangerous content. Do not navigate to it, and close the tab.

Testing the tool

Google publishes a research-only test URL that always returns a malicious verdict, which is the safe way to confirm the checker is working:

http://malware.testing.google.test/testing/malware/

Security warning

The test URL above is a controlled environment. If you encounter a suspicious link in the wild, prefer not to open it directly — checking a URL you are unsure about can still expose you.

Module 03

Roadmap Generator

Purpose

The generator builds structured learning paths and curated resources for a target role or certification. It is educational material, not a substitute for professional training.

Data usage & rate limiting

Generation is rate limited. Each visitor is entitled to a set number of roadmap generations per day, and excessive or automated requests may be restricted temporarily.

Saved progress

The current roadmap and your weekly completion ticks are stored in this browser's local storage only. Nothing is uploaded. Clearing site data, or pressing Clear, removes both.

Content disclaimer

Roadmaps are generated by an AI model from external search results. Accuracy is best-effort, and you are responsible for verifying the relevance and safety of any third-party link before you follow it.

Ask for something narrower

Instead of how to learn cyber security, try 4-month roadmap for CompTIA Security+ prep for structured, certification-focused output.

Module 05

Geo IP Reconnaissance

Overview

The GeoIP module runs passive localisation queries against the HackerTarget API. It maps remote server points, tracks domain routing layers and locates the coordinates of an asset's infrastructure.

Operating instructions

  1. Enter a target indicator. Both raw IP addresses (for example 8.8.8.8) and domain strings (for example target-site.com) are accepted.
  2. Press Initiate scan to query the HackerTarget nodes.
  3. The telemetry report is parsed, structural values are isolated, and the map renders when valid coordinates are returned.

Telemetry log breakdown

Field Description and security value
IP address The resolved network endpoint address of the target.
Country / ASN Identifies the country registration and the autonomous system hosting the hardware.
Latitude & longitude The coordinates used to plot the physical site footprint.

Accuracy notice

GeoIP metrics describe infrastructure locations such as data centres and ISP routing hubs. They do not indicate the physical home address of an individual client.

Module 04

Credential Breach Scanner

Overview

The breach scanner audits an email address or account username against aggregated archives of historical data breaches via the LeakCheck public database.

Privacy standard

The lookup is passive and read-only. Your passwords are never analysed, transmitted or logged by this tool.

Operating instructions

  1. Enter an email address or a service username into the query field.
  2. Press Audit record to dispatch the request to the verification proxy.
  3. The public breach indexes are queried and a verdict returns within seconds.

Interpreting results

Secure

The identifier has zero known exposure signatures across the queried public indexes. No immediate action is necessary.

Critical alert

The identifier was found exposed in breach data. The result lists the specific source breaches.

Recommended remediation

If your account returns a compromised verdict:

  • Rotate the credential. Change the password on the affected account immediately, using a high-entropy value.
  • Stop reusing passwords. An exposure on one platform exposes every service that shares the credential.
  • Enable MFA. Add an authenticator app or hardware key across your accounts.
  • Expect targeted lures. Attackers use breached details to make follow-up phishing convincing.
Module 07

Technology Recon Node

Overview

The scanner fingerprints the technologies behind a target: content management systems, blogging platforms, analytics packages, JavaScript libraries, web servers and embedded devices. It reports versions, framework modules, and security headers.

Operating instructions

  1. Enter the target domain or URL.
  2. Press Scan target, or press Enter inside the input.
  3. Review the handshake, fingerprint and security header groups.

Authorised use only

Scan only hosts you own or have explicit permission to assess. Fingerprinting is an active request to the target.

Module 08

Domain & IP Ownership Trace

Overview

WHOIS is the standard protocol for retrieving the public registration data of a domain or IP address. Analysts use it to audit network allocations, verify domain age to spot newly registered phishing infrastructure, track expiry timelines and assess certificate status.

Operating instructions

  1. Enter a domain or IP address.
  2. Press Execute trace, or press Enter inside the input.
  3. Review the registration table and the raw registry dump below it.

Reading the certificate row

  • Valid — an active certificate, with days remaining shown.
  • Not applicable — expected for raw IP address lookups.
  • Anything else — treat the target with suspicion until resolved.

A domain registered within the last few days, with no valid certificate, is a pattern worth investigating on its own.
